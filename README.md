GenAI Usage:  
The page "Resume" or "Experimental" is created using Claude Sonnet 5. It was used to generate the HTML and CSS of the page based on a given pdf resume. It was guided to create a structural layout for the page first, before writing code.  

The prompts used were as follows:  
1. roleplay a software engineer. your task is to build an html webpage to showcase a client's work experience, skillset, and software knowledge. describe the structure you would use for a layout (no code).  
2. the content buckets will be: work history, skills/tools, identity, and contact   
3. remove the header, I already have a header made  
4. use cards for work history. this will be a plain scroll on one page  
5. create the HTML skeleton first  
6. use the information from this resume  
7. add css
